# Box Cricket browser prototype

This is the first browser-first prototype for the Box Cricket game. It is intentionally a physics test, not the final game.

## Play locally

Open `index.html` in a modern browser. Tap or click the left, centre, or right part of the court to choose a lane, then select **Launch ball**.

The ball scores on its first contact with a scoring wall:

- Front wall: lower half = 4, upper half = 6
- Side walls: lower half = 1, upper half = 2

## Publish with GitHub Pages

After this repository is pushed to GitHub:

1. Open the repository on GitHub.
2. Select **Settings** → **Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Choose `main` and `/ (root)`, then select **Save**.

GitHub will display the public browser-test link after deployment.
